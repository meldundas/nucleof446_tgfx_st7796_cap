# GEMINI.md

## Project Overview

This is an embedded C/C++ project for the STM32F446RE microcontroller, developed using STM32CubeIDE. It utilizes the TouchGFX framework to create a graphical user interface on an ST7796-based display with an FT6336 capacitive touch controller.

The application displays a simple counter with "up" and "down" buttons and a scroll wheel/slider to adjust the count.

### Key Technologies & Libraries:

*   **MCU:** STM32F446RE
*   **Frameworks:** STM32Cube HAL, TouchGFX
*   **Display:** ST7796
*   **Touch Controller:** FT6336 (I2C) or XPT2046 (SPI)
*   **External Flash:** W25QXXX (SPI) for storing graphics assets.

### Architecture:

*   **`Core/`**: Contains the main application logic (`main.c`), peripheral initialization (`stm32f4xx_hal_msp.c`, etc.), and interrupt handlers (`stm32f4xx_it.c`).
*   **`Drivers/`**: Includes the STM32F4xx HAL drivers and CMSIS core files.
*   **`TouchGFX/`**: Contains the TouchGFX application code.
    *   **`App/`**: TouchGFX main entry point (`app_touchgfx.c`).
    *   **`gui/`**: Contains the UI screens (`screenView.cpp`, `screenPresenter.cpp`), and model (`Model.cpp`).
    *   **`target/`**: Holds the hardware abstraction layer for TouchGFX, including display and touch controller drivers.
*   **`*.ioc`**: STM32CubeMX project file, which defines the hardware configuration and pinout.

## Building and Running

This project is intended to be built and run using **STM32CubeIDE**.

1.  **Open STM32CubeIDE.**
2.  **Import the project:** `File -> Import -> General -> Existing Projects into Workspace`.
3.  **Build the project:** `Project -> Build All` (or press `Ctrl+B`).
4.  **Run/Debug:**
    *   Connect the Nucleo-F446RE board to the computer.
    *   Run or debug the application by selecting the `nucleof446_tgfx_st7796_cap Debug.launch` configuration.

A pre-built `.stldr` file for a W25Q128 flash memory is included, which suggests that an external flash is used for TouchGFX assets. This needs to be programmed to the board, likely via the STM32CubeProgrammer.

## Development Conventions

*   The code follows the structure generated by STM32CubeMX and TouchGFX.
*   User code is expected to be added in the `/* USER CODE BEGIN */` and `/* USER CODE END */` sections to preserve it when regenerating code from the `.ioc` file.
*   The UI is designed and managed through the TouchGFX Designer. Changes to the UI should be made in the TouchGFX Designer, which will then generate the necessary code.
*   The application logic for the UI is implemented in the `screenView.cpp` and `screenPresenter.cpp` files.
